The ESP32_IOT_Control_Board_V1.0 is a compact, ESP32-based control board designed for smart home and industrial automation applications. 
It integrates Wi-Fi and BLE connectivity, enabling seamless cloud and local communication. 
The board features 4-channel relay outputs for reliable control of AC and DC loads. 
An onboard flame detection sensor interface enhances safety and monitoring capabilities. 
The power section supports a wide input range (90–264V AC) with onboard regulation for stable 5V and 3.3V outputs. 
Auto-reset and auto-boot circuitry simplify firmware uploading and development. 
Built-in protection components such as polyfuse, TVS diodes, and flyback diodes improve reliability. 
User-programmable status and relay LEDs provide real-time visual feedback. Multiple GPIO, UART, and I²C interfaces allow easy expansion with external sensors and modules. 
Overall, the board is optimized for robust, scalable, and production-ready IoT solutions.
